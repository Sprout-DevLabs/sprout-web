A fast, single-binary directory explorer. It respects .gitignore, shows git changes and hotspots in the tree, renders a PR as a tree, and hands LLMs a compact project map.

$ brew install sprout-devlabs/tap/sprout

or go install github.com/Sprout-DevLabs/sprout@latest · binaries for macOS, Linux, Windows

sprout --ai

Context for LLMs, sized to fit

What the project is, its stack, entry points, CI and config, uncommitted work, recent hotspots, and the directory structure. Never file contents.

Sprout fills a token budget breadth-first, so you get the whole shape of the project before the detail of one corner.

$ sprout --ai --budget 500 | pbcopy

A pull request, as a tree

Only the paths a branch touched, nested in place, with line counts rolled up per folder. -L collapses deep subtrees into totals, so a 200-file PR still fits on one screen.

$ sprout --diff main...HEAD -L 1
. main...HEAD
├── .github/  (2 changed)  +13 -28
├── cursed_renderer.go  M  +67 -17
├── cursed_renderer_test.go  M  +123 -0

sprout --git  ·  sprout --churn

Changes and hotspots, where you're already looking

--git marks modified, added, renamed and untracked files, and shows deleted files where they used to be. --churn shows how many commits touched each path, so the busiest code stands out.

$ sprout --churn -L 1
.
├── README.md  ▂ 23
├── cursed_renderer.go  ▇ 86
├── examples/  █ 141
└── tea.go  █ 93

$ sprout --git -L 1

├── key.go  D
├── newfile.go  ?
└── tea.go  M
sprout mcp

Built for coding agents

Sprout runs as an MCP server. Claude Code, Cursor and other agents get the project map, trees and PR diffs in one call, instead of spending context on ls -R.

Paths stay inside the project, symlinks included. Setup →

$ claude mcp add sprout -- sprout mcp

// or, in any MCP client config
{
  "mcpServers": {
    "sprout": { "command": "sprout", "args": ["mcp"] }
  }
}

tools: project_map · tree · diff_tree

Good defaults, no surprises

Most of the time plain sprout is the right command.

.gitignore-aware

In a repo, git decides what's shown. Outside one, node_modules, .venv, dist and friends are hidden.

Never silent

The last line counts what was hidden. --all brings it back.

Scriptable

--json with a versioned schema. Color only on terminals, and NO_COLOR is respected.

One small binary

About 1 MB, standard library only. Linux, macOS and Windows on amd64 and arm64.
