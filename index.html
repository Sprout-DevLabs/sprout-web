your-project/ ├── only what matters ├── what changed, and where └── a map your AI agent can read

Sprout is a directory tree that understands projects. It respects your .gitignore, marks changes and hotspots in place, shows a pull request as a tree, and gives LLMs a compact project map. One small binary, no dependencies.

or go install github.com/Sprout-DevLabs/sprout@latest

One project, seen four ways

This is real Sprout output for trailhead, a sample trail-map app with a Go API and a React frontend, partway through a feature branch. Pick a command to see what it shows.

    $ sprout -L 2

    Context that fits the window

    sprout --ai writes a plain-text map for a prompt or an agent: what the project is, its stack, entry points, CI and config, uncommitted work, recent hotspots, and the layout. It never includes file contents.

    You set a token budget. Every folder starts as a one-line summary and opens breadth-first while the map still fits, with your own code before tests and fixtures. Drag the slider to watch it spend the budget.

    smallereverything
    $ sprout --ai --budget 300

    Give your coding agent the map

    Sprout runs as an MCP server. Claude Code, Cursor and other agents can get oriented in one call, instead of spending their context on ls -R and find.

    The server is read-only, and paths can't leave the project, even through symlinks. MCP setup

    claude mcp add sprout -- sprout mcp
    • sprout mcp/
    • ├── project_mapthe --ai map, for getting oriented
    • ├── treeany folder, with git status or churn
    • └── diff_treewhat a branch changed

    Plain sprout is usually enough

    The defaults are chosen so you rarely need a flag. Anything Sprout hides is counted on the last line, and --all shows it again.

    • defaults/
    • ├── In a git repo, .gitignore decides what's shown
    • ├── Outside git, node_modules, .venv, dist and friends are hidden
    • ├── Flags work before or after the path
    • ├── Color only in terminals, and NO_COLOR is respected
    • ├── --json for scripts, with a versioned schema
    • └── About 1 MB for Linux, macOS and Windows, with no dependencies
